تنظیماتی که نیاز هست برای اجرای پروژه html رو اضافه کن توی flutter. مثلا اجازه ادرس های بدون (اگر نیاز هست) و  غیره.  مسیر پروژه html همیشه باید ثابت باشد مثلا www/index.html ولی assets باید متغیر و قابل تنظیم باشد تا با هر نوع پروژه ای همخوانی داشته باشد. 15 تا باگ و 3 تا نقطه ضعف رو برطرف کن و و بخش اجرای پروژه های html رو اضافه کن و فایل های جدید رو بصورت کامل برام بنویس. تا بعد از این مرحله plugin ها رو توسعه بدیم.
